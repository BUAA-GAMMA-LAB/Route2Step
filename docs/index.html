TL;DR

Vision-and-language navigation requires an agent to identify which route step is active and to execute that step from egocentric observations. Route2Step decouples these capabilities: the Instruction Analysis Module (MIA) predicts the active sub-instruction and execution state from the full route context, while the Action Generation Module (MAG) produces local action chunks conditioned on that state. E-SPA supplies step-level alignment for route demonstrations without additional manual temporal labels.

Approach

Route-level understanding and step-level execution

The explicit interface makes errors easier to separate. State-level corrective supervision teaches MIA to maintain or update semantic progress, while selective action supervision is reserved for local recovery when repeated attempts fail under the correct active step.

E-SPA alignment

Energy-minimizing Semantic Path Alignment associates fine-grained sub-instructions with contiguous trajectory segments. The resulting alignments support step-conditioned supervision for both modules.

Level-separated correction

Off-path histories can correct semantic progress without conflating that error with local action execution, improving recovery while keeping the target step explicit.

Getting started

The release provides evaluation code. Datasets, scene assets, trajectory images, checkpoints, and the external vLLM server are not bundled with the repository. 

conda create -n route2step_py310 python=3.10 -y
conda activate route2step_py310
pip install -r requirements_eval.txt

Static M1 evaluation

TASK_TYPE=single_m1 \
DATASET=rxr_deviation \
RESULT_DIR=eval_results/m1/rxr_deviation \
bash scripts/eval_m1_static_qa.sh

See the README for navigation evaluation commands and expected paths.
