The idea

Navigation has two different problems.

A VLN agent must know which step of the route is active and also know how to execute that step from its current observations. Route2Step makes this distinction explicit. The system uses one module to track semantic progress and another to generate local action chunks, so an off-path state can be corrected at the right level.

Method

A clean interface between understanding and action.

Route2Step decouples route-level reasoning from step-level execution while keeping the interface interpretable and trainable.

↗

E-SPA alignment

Energy-minimizing Semantic Path Alignment associates fine-grained sub-instructions with contiguous portions of route-level demonstrations without requiring new manual temporal labels.

◎

Level-separated correction

State-level supervision teaches MIA to maintain or update semantic progress, while selective action supervision teaches MAG how to recover local execution.

↔

Designed for transfer

The explicit interface supports controlled off-path evaluation, transfer to existing VLN policies, and deployment in real indoor and outdoor environments.

Quick start

One environment to evaluate.

The release focuses on evaluation. Training-only dependencies can be added to the same Conda environment later.

View requirements_eval.txt ↗
terminal
conda create -n route2step_py310 python=3.10 -y
conda activate route2step_py310
pip install -r requirements_eval.txt

Use the code

Start with the released evaluation scripts.

Configure local data paths and launch an OpenAI-compatible vLLM server before running the commands below.

01Static QA

M1 static evaluation

Evaluate active-step prediction and recovery state on R2R or RxR cases.

TASK_TYPE=single_m1 \
DATASET=rxr_deviation \
RESULT_DIR=eval_results/m1/rxr_deviation \
bash scripts/eval_m1_static_qa.sh
02Navigation

R2R-CE navigation

Configure the M1 and M2 servers, model paths, and data paths in the R2R script.

bash scripts/eval_qwen2_5_dual_lm.sh
03Navigation

RxR-CE navigation

Use the RxR configuration and launch the dual-module navigation evaluation.

bash scripts/eval_qwen2_5_dual_rxr.sh
i

Datasets, scene assets, trajectory images, checkpoints, and vLLM are not bundled with the code. See the repository README for the expected paths and release notes.
